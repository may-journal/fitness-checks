# changelog-bullets

Keeps changelog entries tight: every [entry file](https://github.com/may-journal/fitness-checks/blob/main/cmd/fitness-check-changelog/README.md#entry-files)'s `###` section must have 3 to 5 bullets, each under 365 characters. Each bullet starts with a semantic type, as `Feat:` or `feat(scope):`.

## Behavior

[Requirement 0001](docs/requirements/0001-changelog-bullets-are-few-short-and-typed.md)

## Example

```
fitness changelog-bullets
```

It reads no `.fitnessrc.json` key.
