# no-contrastive-reframing

Flags the "not X, it's Y" reframing in markdown prose. Such a sentence rejects a claim and then restates the real point. An example is `It's not a workout. It's a lifestyle.` It favors precision over recall, so it fires narrowly and leaves ordinary negations alone.

## Behavior

[Requirement 0001](docs/requirements/0001-prose-states-the-point-directly.md)

## Example

```
fitness no-contrastive-reframing
```

It reads no `.fitnessrc.json` key.
