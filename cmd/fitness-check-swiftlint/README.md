# swiftlint

Runs SwiftLint over the repo through the Swift language module, which owns the tool run and its judgment, via `swiftlint lint --strict`. [SwiftLint](https://github.com/realm/SwiftLint) is a system binary. It is on by default.

[Requirement 0001](docs/requirements/0001-swift-code-passes-swiftlint.md) states what this check does, and a test case named for each step proves it.
