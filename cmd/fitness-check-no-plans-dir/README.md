# no-plans-dir

Keeps plans and temporary design work out of the repo. Plans live as `Plan`-labeled GitHub Issues. Mockups, screenshots and validation reports live in issue or pull request comments. It judges every path in the repo, not only `docs/plans/`, and points each offending file to the comment it belongs in.

## Behavior

[Requirement 0001](docs/requirements/0001-plans-and-design-work-stay-out-of-the-repo.md)

## Example

```
fitness no-plans-dir
```

It reads no `.fitnessrc.json` key.
