# architecture-journey

Keeps the user journey diagram and the requirement docs covering each other, and the journey doc free of new sections. Every requirement doc ID appears in a journey diagram label, and every journey node that promises behavior names one. It reads the shared model from `internal/architecture.Load`.

## Behavior

[Requirement 0001](docs/requirements/0001-journey-and-requirement-docs-cover-each-other.md)

## Example

```
fitness architecture-journey
fitness architecture-journey --fix
```

It reads no `.fitnessrc.json` key.
