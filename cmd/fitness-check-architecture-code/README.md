# architecture-code

Resolves each class of the code view to a declaration a language module's reader reads. It keeps the relations between them to the edges the view draws. It reads the model `architecture-contract` describes and adds no fields or columns. Labels, class bodies, arrows, annotations, and row links already say it all.

## Behavior

[Requirement 0001](docs/requirements/0001-code-view-matches-the-source.md) states what this check does, and a test case named for each step proves it.
