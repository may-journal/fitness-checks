# fitness-checks

The fitness checks that the [fitness-runner](https://github.com/may-journal/fitness-runner) engine runs. Each check will live here with its README, tests, fixtures and language modules, on its own release line, while the engine stays small and stable.

The engine, hooks, workflows and installer stay in fitness-runner, and the release build still compiles one `fitness` binary. The move is planned in [Split fitness-runner into an engine repo and a checks repo](https://github.com/may-journal/fitness-runner/issues/918). Until it lands, the checks still live in fitness-runner.
