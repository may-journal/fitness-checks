### 2026.11.18.0300

> A repo can renumber its requirement docs and record each move in a checked-in map.

- Feat: `requirements` reads `docs/requirements/renumber.txt`, where each `old -> new` line moves a doc or an acceptance.
- Feat: an ID the map lists, or an acceptance of a listed doc, is free to reuse; unlisted removals still fail.
- Feat: a malformed map line, an old ID listed twice, or a target no doc defines fails, naming the line.
- Fix: git history reads only Markdown docs, so a `#` comment in the map never reads as a removed title.
- Test: new requirement 0170 covers reuse after a move, the map's line rules, and moved tests.
