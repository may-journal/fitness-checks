### 2026.11.14.2000

> A pull request builds and tests only the checks it can change.

- Ci: the Checks workflow runs `scripts/test-check.sh` on each check that `scripts/changed-checks.sh` names, one job per check.
- Ci: the same workflow runs `tests/requirements.sh` against the check programs on every change to code or requirements.
- Build: `scripts/changed-checks.sh` names a check when its folder, a package it imports or a file one embeds changes, and every check for `go.mod`.
