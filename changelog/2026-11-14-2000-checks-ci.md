### 2026.11.14.2000

> A pull request builds and tests only the checks it can change.

- Ci: the Checks workflow builds, vets and tests each check that `scripts/changed-checks.sh` names, one job per check.
- Ci: the same workflow runs `tests/requirements.sh` against the check programs on every change to code or requirements.
- Build: `scripts/changed-checks.sh` names a check when its folder changes or its `go list -deps` holds a changed package, and every check for a `go.mod` change.
